**1. There are three types of version control.**

[ Local Version Control System- a database system:
 on a single local computer used tracking changes to files. Due to crashes and loss of history local databases ]
[Centralized Version Control System: A central sever controlled by a hub that hold all saved versions of files at for collaborators. They are able to save and download file version but if the host is down they do not have access.]   
[Distributed Version Control System: In this system all developers use a central sever which saves all versions for cloning a complete repository with all versions available to the developers for download locally and any developer can restore files if lost.]
